# Auaka Knowledge Space Frontend

The browser runtime will load the versioned knowledge-space artifact and render
it with Three.js. Task 1 provides only the Vite/TypeScript scaffold.

```powershell
npm install
npm run dev
npm run build
```

Public artifact and model paths are configurable through `VITE_` environment
variables. The local Hand Landmarker asset will be added in a later task.
